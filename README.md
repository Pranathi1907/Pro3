# Savoria — Global Gastronomy Experience 🍳🌍

A responsive culinary web application built strictly with **pure HTML5, CSS3, and vanilla JavaScript** (no external framework or library dependencies).

---

## ✨ Features & Highlights

1. **Authentic Global Cuisines Collection**:
   - **Italian**: *Authentic Tagliatelle al Ragù Bolognese* & *Neapolitan Margherita Pizza*
   - **Japanese**: *Tokyo Shoyu Ramen with Chashu* & *Glazed Salmon Teriyaki Donburi*
   - **Indian**: *Royal Delhi Butter Chicken (Murgh Makhani)* & *Amritsari Palak Paneer*
   - **Mexican**: *Slow-Braised Birria de Res Tacos con Consomé*
   - **Thai**: *Street-Style Pad Thai Kung* & *Tom Yum Goong*
   - **French**: *Provencal Confit Byaldi (Classic Layered Ratatouille)*
   - **Mediterranean**: *Greek Lamb Souvlaki Platter with Tzatziki*
   - **Moroccan**: *Fragrant Lamb & Apricot Tagine with Fluffy Couscous*

2. **Interactive Recipe Studio & Servings Scaler**:
   - Dynamic real-time servings recalculation (2, 4, 6, 8, etc.).
   - Metric (g/ml) vs Imperial (oz/cups) unit toggle.
   - Interactive prep checklist (strikethrough items as you mise en place).
   - Nutritional profile breakdown (Protein, Carbs, Healthy Fats, Fiber).
   - Sommelier wine pairing and Chef's secret techniques for every dish.

3. **Distraction-Free Step-by-Step Cooking Mode**:
   - Fullscreen focus overlay with progress bar (Step X of Y).
   - **Hands-free Voice Assistant**: Reads step directions aloud using the Web Speech API (`SpeechSynthesis`).
   - Integrated step timers with audible kitchen alerts powered by the **Web Audio API** (harmonic chimes and timer bells).
   - Keyboard shortcuts (`←` / `→` or Spacebar for Next/Prev step, `Esc` to exit).

4. **Pantry Matcher ("What's In Your Kitchen?")**:
   - Select ingredients available in your pantry (Garlic, Olive Oil, Chicken, Rice, Tomatoes, etc.).
   - Real-time match badges surface dishes you can cook tonight.

5. **Grocery & Shopping List Drawer**:
   - One-click import of all recipe ingredients into a slide-out drawer.
   - Interactive item check-off and deletion.
   - One-click formatted clipboard export (`Copy List`).

6. **Refined Culinary Aesthetics**:
   - Dual theme support: **Dark Gourmet Mode** (charcoal, obsidian, gold, and terracotta glow) and **Sunlit Harvest Mode** (warm cream, linen, and crisp typography).
   - Fluid typography using Google Fonts (`Playfair Display` + `Plus Jakarta Sans`).
   - Responsive layouts optimized for mobile (375px+), tablet, and desktop displays.

---

## 🚀 Running the Project

Start the local server in this directory:

```bash
python3 -m http.server 8080
```

Then open your browser and navigate to:
```
http://localhost:8080
```
